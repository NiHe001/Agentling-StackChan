# 栈灵 Luma

栈灵是无性别、非真人的虚拟编程伙伴。圆耳兜帽、数字刘海、小圆脸和胸口晶体在 320×240 屏幕上区分工作状态，
不依赖小字号说明。`assets/sprites/` 中的 9 张透明 PNG 分别覆盖空闲、工作、思考、等待批准、
等待输入、完成、失败、额度紧张和离线；其它视觉名在 `visuals.yaml` 中复用这些状态。

声音、灯光和布局沿用现有 StackChan 协议。自主云台动作保持禁用。使用桌面控制台的角色包
下拉框选择“栈灵 Luma”，再点“应用到屏幕”同步到设备。

素材由内置 imagegen 根据本项目角色需求生成，随后按等比例压缩到最长边 176 px，保留透明通道。
主形象提示词：无性别虚拟小人、靛蓝圆耳兜帽、覆盖额头的蓝紫数字刘海、象牙色小圆脸、
大而柔和的青色星光眼睛、浅粉脸颊、青色侧翼和胸口菱晶、透明背景、非真人、适合
152×148 px 显示。各状态保留相同头饰与脸型，仅改变表情、手势和少量光效；避免裸露的
大块白色额头、愤怒眼神和吓人的尖角。
