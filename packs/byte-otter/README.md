# Byte Otter

`Byte Otter` 是本项目的原创程序员伙伴角色，不基于现有动漫、游戏、企业吉祥物或商标。
角色采用水獭、深色连帽衫、机械键盘和抽象终端元素，包含空闲、编码、专注、思考、等待批准、
成功、失败、额度提醒、连接、睡眠和离线等状态。

## 动画与硬件行为

- `png_sequence` 在一组状态帧间切换，`animation` 提供轻微呼吸、浮动、工作和提醒动效。
- 角色状态表保留 362×362 原稿；设备包使用 176×176 透明 PNG，在 320×240 屏幕中央完整显示。
- 固件 0.2.x 明确关闭头部云台供电；角色包不声明舵机动作。
- 左右各 6 颗灯使用相同相位和镜像位置刷新，支持常亮、呼吸、脉冲和流动模式。
- 优先使用已插入的 microSD/TF 卡保存角色包，未检测到卡时回退到内部 LittleFS。
