# Byte Otter sprite-sheet generation prompt

Built-in image generation was used to create one transparent 4 by 3 sprite sheet for an original,
gender-neutral chibi river-otter programmer. The character has cocoa-brown fur, a cream muzzle, a
dark navy hoodie with mint and amber accents, and a tiny abstract terminal badge. The twelve cells
show idle, coding, thinking, approval, success, error, low quota, sleeping, curious, connecting,
focused, and offline states. The prompt explicitly excluded existing characters, brands, logos,
watermarks, signatures, and recognizable costumes.

Generated source: `design/byte-otter-sprite-sheet.png`.
